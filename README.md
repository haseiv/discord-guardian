# Discord Guardian

Discord-бот на TypeScript с защитой сервера, тикетами, временными голосовыми комнатами и публикацией сообщений от имени бота. Настройка выполняется slash-командами прямо в Discord. Интерфейс и сообщения бота — на русском языке.

## Возможности

- **Антирейд:** обнаруживает массовые входы за заданное окно времени и выдаёт временный таймаут участникам волны и новым участникам в течение защитного периода. Можно задать минимальный возраст аккаунта для входа.
- **Антинюк:** отслеживает массовые изменения каналов, ролей, вебхуков, банов, киков и настроек сервера через журнал аудита. При превышении порога применяет бан, кик или снятие доступных ролей с таймаутом. Владелец сервера и доверенные пользователи исключаются.
- **Антифлуд:** таймаут за слишком частую отправку сообщений. Содержимое сообщений бот не читает.
- **Тикеты:** панель с кнопкой, приватный канал для автора и поддержки, закрытие автором или поддержкой, текстовый журнал последних 1000 сообщений.
- **Голосовые комнаты:** вход в лобби создаёт временную комнату. Панель позволяет сменить название, лимит, закрыть или открыть комнату; команды позволяют пригласить, отключить участника и передать владение. Пустая комната удаляется.
- **Публикация:** `/publish text` и `/publish embed` отправляют сообщение от имени бота без массовых упоминаний.

## Быстрый запуск

Нужен Node.js 22 или новее. Создайте приложение и бота в [Discord Developer Portal](https://discord.com/developers/applications). В разделе **Bot** включите привилегированный intent **Server Members Intent**. **Message Content Intent не требуется**.

1. Скопируйте `.env.example` в `.env` и заполните `DISCORD_TOKEN` и `DISCORD_CLIENT_ID`. Для тестового сервера можно указать `DISCORD_DEV_GUILD_ID`, чтобы команды появились сразу. Не публикуйте `.env`.
2. Установите зависимости: `npm ci`.
3. Проверьте проект: `npm run check`.
4. Запустите: `npm run build && npm start`.
5. Пригласите бота через OAuth2 URL Generator со scope `bot` и `applications.commands`. Права: **View Audit Log, Manage Channels, Manage Roles, Moderate Members, Ban Members, Kick Members, Move Members, View Channels, Send Messages, Read Message History, Embed Links, Attach Files**. Разместите роль бота выше ролей, которые он должен снимать. Выдавайте только необходимые права для включённых функций.

Данные настроек хранятся в `data/state.json`. Сохраняйте этот файл при переносе или обновлении бота. Запускайте только один экземпляр, использующий один файл данных.

## Настройка в Discord

| Команда | Назначение |
| --- | --- |
| `/guardian status` | Показать настройки защиты |
| `/guardian logs` | Выбрать канал журнала безопасности |
| `/guardian toggle` | Включить или выключить защиту |
| `/guardian raid` | Настроить порог массового входа и длительность таймаута |
| `/guardian account-age` | Минимальный возраст аккаунта, `0` отключает проверку |
| `/guardian antinuke` | Настроить порог опасных действий и санкцию |
| `/guardian spam` | Настроить антифлуд |
| `/guardian trust-add`, `/guardian trust-remove` | Управлять доверенными пользователями |
| `/tickets setup`, `/tickets panel` | Настроить тикеты и разместить панель |
| `/rooms setup`, `/rooms panel` | Настроить лобби и разместить панель комнат |
| `/room invite`, `/room transfer`, `/room kick` | Управлять своей комнатой |
| `/publish text`, `/publish embed` | Опубликовать сообщение от имени бота |

Сначала выполните `/guardian logs`, `/tickets setup` и `/rooms setup` для нужных функций. Команды настройки доступны участникам с правом **Manage Server**, публикация — с **Manage Messages** в выбранном канале.

## Важные ограничения

Защита от ньюка реагирует **после** появления записей в журнале аудита: она ограничивает дальнейшие действия нарушителя, но не восстанавливает уже удалённые каналы и роли. Discord также не позволяет боту наказать владельца сервера или участника с ролью выше роли бота. Для полной защиты включите встроенные инструменты безопасности Discord, ограничьте административные права и делайте резервные копии структуры сервера.

Режим антирейда хранится в памяти и после перезапуска сбрасывается. Таймауты, уже выданные участникам, остаются на стороне Discord. Журнал тикета содержит максимум 1000 последних сообщений и ссылки на вложения, а не сами файлы.

## Разработка

`npm run dev` запускает бота с перезагрузкой кода. `npm run check` проверяет типы. `npm run build` собирает JavaScript в `dist/`. Токен и файл данных исключены из Git.
